# Nyeleti Construction Website

## About the project
This website introduces Nyeleti Construction and provides information about the company, its services, projects and contact details. Visitors can browse the pages and send an enquiry.

## Website pages
- **Home:** Introduction to the company and its services.
- **About Us:** Company background, vision, mission and values.
- **Services:** Construction services offered.
- **Enquiry:** Form for requesting information or a quotation.
- **Contact Us:** Contact details and map.
- **Gallery:** Images of construction materials and projects.
- **References:** Online resources used for website development.

## Technologies
- HTML for page structure and content.
- CSS for colours, layout and responsive styling.
- JavaScript for the page search, gallery lightbox, form validation support, back-to-top button and copyright year.
- GitHub Pages can be used to publish the website.

## Project folders and files
- HTML files: the six website pages.
- `style.css`: main website styling.
- `js/site.js`: external JavaScript features.
- `images/`: website images and logo.
- `documents/`: supporting project documents.
- `CHANGELOG.md`: summary of Part 3 changes.

## How to view the website
Open `home page.html` in a web browser to view the website locally. Use the navigation menu to open the other pages. If published with GitHub Pages, use the live website address shown in the repository settings.

## Important functionality notes
The search box checks the page that is currently open and provides links to other matching pages on the website. The enquiry and contact forms currently use placeholder form actions and do not send messages to an email address or database. The contact page map searches for Behnya Street, Katlehong, Gauteng, South Africa. Use the Google Maps link on the page to check the location.
