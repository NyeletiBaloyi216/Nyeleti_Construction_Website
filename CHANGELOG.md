# Changelog – Nyeleti Construction Website

## Part 3 updates

This file records the changes made to improve the website after Part 2.

- Added page-specific meta keywords and author information to the six website pages.
- Checked page titles and meta descriptions so that each page describes its own content.
- Added a search box to each page. The search checks sections on the current page and also provides links to matching pages across the website.
- Added a gallery lightbox. Visitors can open an image, move to the previous or next image, and close the viewer. Keyboard controls are also supported.
- Added a back-to-top button and automatic copyright year.
- Kept JavaScript in one external file at `js/site.js` and linked it to the HTML pages.
- Added responsive styling for the search box, lightbox and back-to-top button while keeping the existing navy, gold and white website design.
- Kept the existing contact map and forms, and retained browser validation for required form fields.

## Notes

- The search checks the page currently open and provides matching page links using a small website page index.
- The contact form uses `action="#"`; it does not send submissions to an email address or database until a form service or server-side handler is connected.
- Updated the contact map to search for Behnya Street, Katlehong, Gauteng, South Africa, and added a link to open the location in Google Maps. The map search result should be checked in a browser to confirm that Google Maps identifies the correct street.
- Meta keywords are included because they appear in the assignment rubric. Major search engines may not use them for ranking.

- Renamed image files with descriptive names and updated their HTML references and alternative text.

- Fixed malformed footer opening tags found during the final file review.
- Added a References page and linked it from the website footers.
- Added a References section to the README file.

- Updated the phone number and email address across the website using the business contact details supplied, and confirmed the Behnya Street, Katlehong address in the project documentation.
